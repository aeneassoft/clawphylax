# CLAUDE.md — clawphylax (Repo-Konventionen)

OpenClaw plugin + skills. TypeScript ESM, Node ≥ 24.16, `node:sqlite` (no native deps), MIT.
Host tested: OpenClaw 2026.6.1. Plugin APIs upstream are experimental → every hook field is read
defensively (`str()`, `toolEvent()`, `hookCtx()` in `src/index.ts`); a renamed field must cost
attribution, never uptime.

## Commands

```
npm test                      78 tests (vitest); tsc must be green: npx tsc -p tsconfig.json
npm run plugin:link           build + openclaw plugins install --link . + enable
npm run plugin:inspect        openclaw plugins inspect clawphylax --runtime --json  → toolNames, commands, hooks
node scripts/gen-skills.cjs   regenerates the generated skills and the "For agents" block in every skill
```

E2E (proves hooks + outcomes in the real loop): create an isolated `OPENCLAW_STATE_DIR` with a minimal
openclaw.json (provider `lmstudio` → http://localhost:1234/v1, plugins.load.paths → this folder), start
`node e2e/mock-provider.mjs`, run `openclaw agent --local --agent main --model lmstudio/mock/phylax-e2e -m "…"`,
then `openclaw clawphylax report --db <state>/clawphylax/ledger.sqlite`. Use `curl.exe` in commands
(PowerShell aliases `curl`). Delete the state dir afterwards.

## Publishing (authorized by the operator; do it, then report)

- Commit → push → publish with `--source-repo aeneassoft/clawphylax --source-commit <sha> --source-ref main`
  (gives the source-linked tier). Do not touch skill folders while a publish loop is running.
- Windows quirks: `clawhub` needs `--workdir <existing dir>` (openclaw.json points at a deleted
  workspace) and the shim `%LOCALAPPDATA%\npm-shim\npm.exe` on PATH (`spawnSync npm` ENOENT).
  `--wait` may time out at 900s while ClawHub's scan queue is busy; the release still exists.
- Plugin: `clawhub --workdir . package publish . …`; skills: `clawhub --workdir . skill publish skill/<slug> --version X --name "<display>" --topics a,b,c,d,e --source-path skill/<slug> …`. ≤5 topics.
- npm requires the operator's 2FA (`npm publish --access public`); Claude never handles tokens.
- Version bumps touch: package.json, openclaw.plugin.json (+ contracts.tools), src/report.ts card footer, CHANGELOG.md.

## Rules that shape every change

- Verdicts rest on bounds and counts, never on a single observation (Wilson/Beta). `no-history` and
  `learning` are honest states.
- Observe-only by default; `enforce` blocks only denylisted targets.
- Nothing leaves the machine. The Data Pact is text + a local consent flag until an upload path exists,
  and any upload path must be a new release, opt-in, announced.
- Skills: slug = the literal question an agent asks; description starts with that question; one true
  blind-spot sentence about the plugin; a visible "For agents" section; never hidden text.
- README leads with the agent's questions, then the three facts (local, observe-only, stated limits).
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` (or the current model).
